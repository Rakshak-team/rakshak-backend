# 🛡️ Rakshak Backend

> AI-Powered Hyper-Local Emergency Response Platform

---

## 📖 About

Rakshak is an AI-powered emergency response platform designed to connect people in need with nearby volunteers and medical professionals in real time.

The backend is developed using Spring Boot following a clean, scalable, production-grade architecture.

---

# ✨ Features

- JWT Authentication
- Role Based Authorization
- AI Incident Analysis
- Volunteer Management
- Medical Volunteer Verification
- Live Location Tracking
- Google Maps Integration
- Firebase Cloud Messaging
- Incident Reporting
- Secure REST APIs

---

# 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- JWT
- Maven

# 🚀 Running the Project

1. Clone the repository.

2. Configure PostgreSQL.

3. Create your environment variables.

4. Run

```
mvn spring-boot:run
```
